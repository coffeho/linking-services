# Предметная область HR System

## 1. Общая идея

HR System — учебная система кадрового учета.

Предметная область проекта связана с хранением и обработкой данных о сотрудниках организации, их должностях, подразделениях, отпусках, переводах и кадровых приказах.

Система моделирует базовые процессы отдела кадров:

- ведение списка сотрудников;
- учет подразделений;
- учет должностей;
- оформление отпусков;
- оформление переводов;
- создание и исполнение приказов;
- просмотр кадровой статистики.

## 2. Основные понятия

### Пользователь

Пользователь — это учетная запись человека, который входит в систему.

Пользователь имеет:

- логин;
- пароль;
- роль;
- полное имя;
- признак активности.

Роль пользователя определяет доступные разделы системы.

В текущей версии используются роли:

- Администратор;
- HR-менеджер;
- Бухгалтер;
- Сотрудник.

### Сотрудник

Сотрудник — это человек, работающий или работавший в организации.

Сотрудник имеет:

- ФИО;
- дату рождения;
- дату приема на работу;
- подразделение;
- должность;
- зарплату;
- статус.

Статус показывает текущее кадровое состояние сотрудника:

- `Работает`;
- `Уволен`;
- `В отпуске`;
- `На больничном`.

Сотрудник связан с подразделением и должностью.

### Подразделение

Подразделение — это организационная единица внутри компании.

Примеры подразделений:

- Бухгалтерия;
- Отдел кадров;
- IT-отдел;
- Отдел продаж;
- Администрация.

Подразделение может содержать нескольких сотрудников.

Если в подразделении есть сотрудники, его нельзя удалить без предварительного изменения данных сотрудников.

### Должность

Должность описывает роль сотрудника внутри организации.

Примеры должностей:

- Менеджер;
- Бухгалтер;
- Программист;
- HR-специалист;
- Директор.

Должность может иметь базовую зарплату.

Если на должности есть сотрудники, должность нельзя удалить.

### Отпуск

Отпуск — это период временного отсутствия сотрудника.

Отпуск содержит:

- сотрудника;
- дату начала;
- дату окончания;
- тип отпуска.

Типы отпусков в текущей версии:

- ежегодный оплачиваемый;
- без сохранения зарплаты;
- учебный;
- по уходу за ребенком.

Дата окончания отпуска не должна быть раньше даты начала.

### Кадровый приказ

Приказ — это кадровый документ, который фиксирует действие по сотруднику.

Приказ может быть связан с сотрудником и иметь дополнительные данные.

В текущей версии поддерживаются типы приказов:

- прием на работу;
- увольнение;
- перевод;
- отпуск;
- изменение оклада;
- премия;
- взыскание.

Приказ имеет статус:

- `Не исполнен`;
- `Исполнен`;
- `Отменён`.

Пока приказ не исполнен, его можно изменять или удалять.

После исполнения приказ считается примененным к данным системы.

### Перевод

Перевод — это изменение подразделения сотрудника.

Перевод содержит:

- сотрудника;
- старое подразделение;
- новое подразделение;
- дату перевода.

Перевод сохраняется в истории переводов.

Сотрудника нельзя перевести в то же подразделение.

## 3. Связи между сущностями

Основные связи:

- пользователь входит в систему и получает доступ в зависимости от роли;
- сотрудник относится к одному подразделению;
- сотрудник занимает одну должность;
- сотрудник может иметь несколько отпусков;
- сотрудник может иметь несколько приказов;
- сотрудник может иметь историю переводов;
- приказ может изменить статус сотрудника, подразделение, должность, зарплату или добавить отпуск.
