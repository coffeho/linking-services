# HR System Documentation

HR System — учебный проект системы кадрового учета на Python и Tkinter.

Документация описывает текущее состояние проекта, предметную область, архитектуру и процесс командной работы.

## О проекте

HR System предназначена для базового кадрового учета организации.

Система включает:

- авторизацию пользователей;
- учет сотрудников;
- работу с подразделениями;
- работу с должностями;
- учет отпусков;
- кадровые приказы;
- переводы сотрудников;
- отчеты и статистику.

Проект развивается постепенно: от исходного монолитного файла `main.py` к структурированному инженерному проекту с выделенным `packages/core`, тестами, документацией и автоматизированными командами.

## Основные команды

Подготовка окружения:

```bash
python3 -m venv .venv
source .venv/bin/activate
make setup
```

Запуск всех тестов:

```bash
make test
```

Ожидаемый результат на текущем этапе:

```text
14 passed
```

Сборка документации:

```bash
make docs
```

## Ограничения текущей версии

Проект находится в процессе рефакторинга.

На текущем этапе:

- основное Tkinter-приложение пока остается в `main.py`;
- часть бизнес-логики и SQL-запросов еще находится в GUI-коде;
- запускаемый слой еще не вынесен в `app/ui`;
- контейнеризация пока не добавлена;
- диаграммы будут добавлены отдельным шагом позже.

## Проверка документации

Документация собирается автоматически через MkDocs:

```bash
make docs
```

Сгенерированный результат помещается в папку `site/`.

Папка `site/` не редактируется вручную и не хранится в Git, потому что документация должна пересобираться из исходных файлов в `docs/`.
