# HR System

Учебный проект: система кадрового учета на Python и Tkinter.

## Текущее состояние

На начальном этапе проект представляет собой один файл `main.py`.

В этом файле сейчас находятся:

- GUI на Tkinter;
- работа с SQLite;
- авторизация пользователей;
- учет сотрудников;
- подразделения;
- должности;
- отпуска;
- приказы;
- переводы;
- отчеты;
- управление пользователями.

Дальше проект будет постепенно преобразован в структурированный инженерный проект согласно требованиям курса.

## Запуск

```bash
python main.py
```
